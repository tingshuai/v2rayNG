# 免费节点功能文档

本目录记录 FreeV2ray 的免费节点功能设计、接口和运行要求。**现行目标设计版本为 `FN-2.0`，实施中，尚未完成验收或部署。** Collector 已增加跨批次筛选游标、探测冷却、来源候选关联和来源均衡的质量加权；Android 已加入近期成功节点保留和隔离节点筛除。完整候选状态机、版本化清单、安全撤销和匿名反馈尚未完成。免费节点功能由用户主动开启；启用后匿名质量反馈默认开启，可单独关闭。未开启用户保持原有 v2rayNG 行为。

每次改变免费节点的决策、接口、实现或运行方式时，必须在同一变更中更新对应文档和本索引。过期内容应删除或明确标为“已废弃”，不得与现行规则并列造成歧义。
