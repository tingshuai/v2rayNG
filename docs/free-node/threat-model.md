# FN-2.0 数据保留与威胁模型

**FN-2.0 目标规则；仅部分客户端和 collector 控制已实现。** 免费节点由未知运营者控制。启用前必须警告用户不要通过它们发送凭据、付款信息或其他敏感数据。功能需用户主动开启；匿名质量反馈随功能默认开启，可单独关闭。当前匿名反馈未实现，不得声称已有上传或聚合。

| 风险 | 控制 |
| --- | --- |
| 私网访问与 DNS 重绑定 | 来源和节点均只接收公开地址；DNS 解析后及连接前再次校验。 |
| 恶意或失效节点 | 安全违规立即撤销；普通故障降级、隔离、有限复测；本地真实结果决定选择。 |
| 大量用户拥挤同一节点 | 加权分配、保守容量上限、来源多样性、节点级聚合分配压力与降权。 |
| 长列表节点永远不被测到 | 各来源基本份额、跨批次轮转和新节点探索预算。 |
| 反馈误报与投毒 | 普通网络健康前置检查、入口限流、跨时间复测；单个报告不得全局删除。 |
| 隐私或凭据泄漏 | 无设备 ID、长期用户—节点映射或请求 IP 留存；日志/反馈不含配置和测试载荷。 |

## 数据类别

| 数据 | 位置与用途 | 删除规则 |
| --- | --- | --- |
| 来源最小配置 | VPS 注册表，按各自周期拉取 | 来源删除时移除；当前非秘密审计记录保留 30 天。 |
| 节点指纹、探测结果、聚合分配计数 | VPS SQLite，跨来源去重、探测冷却、分发加权 | 当前实现按最近出现时间最多保留 30 天；来源成功清单维护指纹关联，过期要求所有关联来源后续成功清单均确认缺席。反馈延期删除尚未实现。 |
| 可还原候选配置 | 临时探测文件与当前发布工件 | 临时 sing-box 配置在探测结束时删除；有效订阅保留到替换，回退副本最长 7 天。完整配置不写入 SQLite、普通日志或仓库。 |
| 原始匿名反馈 | 尚未实现 | 未启用反馈端点，不收集此类数据。 |
| 聚合反馈 | 尚未实现 | 未启用反馈端点，不收集此类数据。 |
| 本机节点配置和探测历史 | Android MMKV，现有探测评分和稳定选择 | 关闭功能时清理专用订阅和历史；新清单缺席时本地保留及过期清理由 FN-2.0 客户端改造实现。 |

候选状态、失败和来源消失规则尚未落地，不得把一次失败或一个来源缺席视作全局删除条件。所有数据只用于该功能。不得上传或记录完整代理 URL、凭据、UUID、私钥、客户端 IP、设备标识、浏览内容或测试载荷；部署文件、数据库和运行输出不得进入仓库。
