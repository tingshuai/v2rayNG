# FN-2.0 数据保留与威胁模型

**目标规则，尚未实现。** 免费节点由未知运营者控制。启用前必须警告用户不要通过它们发送凭据、付款信息或其他敏感数据。功能需用户主动开启；匿名质量反馈随功能默认开启，可单独关闭。

| 风险 | 控制 |
| --- | --- |
| 私网访问与 DNS 重绑定 | 来源和节点均只接收公开地址；DNS 解析后及连接前再次校验。 |
| 恶意或失效节点 | 安全违规立即撤销；普通故障降级、隔离、有限复测；本地真实结果决定选择。 |
| 大量用户拥挤同一节点 | 加权分配、保守容量上限、来源多样性、节点级聚合分配压力与降权。 |
| 长列表节点永远不被测到 | 各来源基本份额、跨批次轮转和新节点探索预算。 |
| 反馈误报与投毒 | 普通网络健康前置检查、入口限流、跨时间复测；单个报告不得全局删除。 |
| 隐私或凭据泄漏 | 无设备 ID、长期用户—节点映射或请求 IP 留存；日志/反馈不含配置和测试载荷。 |

## 数据类别

| 数据 | 位置与用途 | 删除规则 |
| --- | --- | --- |
| 来源最小配置 | VPS 注册表，按各自周期拉取 | 来源被删除时移除；非秘密审计按既定短期窗口保留。 |
| 节点指纹、状态、来源关联、聚合分配/探测计数 | VPS 数据库，去重、调度、分发、失败冷却 | 可用期间保留；删除配置后暂留不可逆失败记录，最长 30 天；长期未见/过期记录清理。 |
| 可还原候选配置 | 受限加密工作区和当前有效发布工件，生成清单 | 临时处理文件完成即删，最长 24 小时；有效发布按清单有效期保留，回退副本最长 7 天。不得进入长期数据库、普通日志或仓库。 |
| 原始匿名反馈 | VPS 受限入口，用于聚合 | 尽快汇总并删除，最长 24 小时；不保留请求 IP。 |
| 聚合反馈 | VPS 数据库，调权与复测 | 最长 30 天；不形成用户画像。 |
| 本机节点配置和探测历史 | Android MMKV，保留旧好节点和稳定选择 | 配置过期、反复失败或安全撤销时删除；失败指纹仅保留冷却所需期限；关闭功能后清理。 |

具体成功、失败和消失的时间阈值在实现前依据来源周期与 VPS 容量确定并更新本文档和测试，不得把一次失败或一个来源缺席当作全局删除条件。所有数据只用于该功能。不得上传或记录完整代理 URL、凭据、UUID、私钥、客户端 IP、设备标识、浏览内容或测试载荷；部署文件、数据库和运行输出不得进入仓库。
