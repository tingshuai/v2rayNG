# 上游同步清单

在开始上游同步或功能分支前：

1. 获取 `upstream/master`，确认远程地址为 v2rayNG 官方仓库。
2. 比较所有 `AGENTS.md` 和路由 shim；本地 FreeV2ray 指令必须保留在本地块中且不得进入功能提交。
3. 检查 FN-2.0 清单解析与合并、MMKV 持久化、真实测速、策略组、Xray 配置生成、WorkManager 和匿名反馈 API 的上游变化。
4. 判断变更是否影响免费订阅契约、指纹迁移、评分/滞回、隔离或后台约束；若影响，在同一变更中更新本目录文档与测试。
5. 对共享代码执行两种发行版所需的构建/测试；涉及 VPN、核心、后台或生命周期时补充设备或模拟器检查。

同步完成后，确认本仓库没有生产地址、凭据、来源 Cookie、节点转储或完整代理配置。
