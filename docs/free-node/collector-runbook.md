# 采集服务运行手册

## 运行边界

采集器独立于 Android 仓库。它只访问经维护者审核并显式配置的公开来源；不保存 VPS 凭据、来源账户 Cookie、生产节点清单或完整代理配置到本仓库。

## 每次运行

1. 拉取白名单来源，并遵守每来源的频率限制。
2. 解析、规范化和去重候选配置。
3. 解析每个目标的 DNS；拒绝非公网地址。连接前重新解析并核验，以防 DNS 重绑定。
4. 在严格的并发、短超时和有限重试条件下做语法、TCP/TLS 和可选 HTTP 204 检查。
5. 发布普通订阅；失败和超时不应阻断上一次有效输出的可用性。

## 事故处理

- 来源返回异常内容、非预期重定向或疑似恶意配置时，立即禁用该来源并保留不含凭据的审计摘要。
- 检查发现私网、环回、链路本地或保留地址时，拒绝候选并记录来源标识与拒绝原因，不能记录完整代理链接。
- 输出异常膨胀、超时或资源消耗异常时，停止该轮并维持最后一次成功发布，调查后再恢复。

采集器不是通用端口扫描器；禁止扩大端口范围、进行高流量下载测试或绕过来源限流。
