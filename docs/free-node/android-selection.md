# FN-2.0 Android 状态与选择

**目标设计，尚未实现。** 客户端仍使用 MMKV、受生命周期约束的后台任务、真实连接测试和 Xray 策略组能力。免费节点功能由用户主动开启；未开启时原有 VPN、仅代理、root 和订阅行为不变。

手机接收 VPS 分配的有限候选清单，并以连接相关字段的设备本地 HMAC 指纹关联历史。新清单与本机仍在保留期且近期测通的旧节点合并；普通清单缺席不删除旧节点。安全撤销、本机多次失败或保留期届满才使节点退出本机可选集合。退出后暂留失败指纹和冷却期限，防止重新下发时立刻重复探测。多记录写入必须原子完成或可恢复。

后台仅测有限候选：近期健康、未测新节点、隔离到期的少量探索样本。无网络、低电量和计费网络使用更严格的预算。当前节点健康且速度可接受时保持；连续失败才进行故障切换。挑战者需要连续明显优于健康当前节点才可替换。服务端质量分数只引导首次探索，不能推翻本机测量。

匿名质量反馈随免费节点功能默认开启，可单独关闭。只有普通网络健康检查成功，且节点探测结果具备上下文时，才发送匿名候选标识、粗粒度结果和时间窗；不上传设备 HMAC 密钥、完整节点配置、设备 ID 或测试载荷。关闭反馈不影响节点更新和选择。启用前继续展示免费节点不适合凭据、支付等敏感流量的警示。

测试必须覆盖清单更新时旧好节点保留、失败节点退出、冷却后恢复、安全撤销、当前节点稳定、后台取消/约束、反馈开关和网络健康前置条件，以及 VPN、仅代理和 root 受影响路径。
