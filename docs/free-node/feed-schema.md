# 订阅与元数据契约

## MVP 输出

MVP 只发布普通 V2Ray 兼容订阅，复用既有订阅解析器。客户端必须能把它当作普通订阅导入和更新；功能不得依赖私有格式才能工作。

订阅中只包含候选代理配置。不要在订阅中下发策略组、自动切换策略、用户标识或追踪参数。策略组由客户端本地维护。

## 可选元数据

如需元数据端点，必须单独提供并版本化，且普通订阅导入不依赖它。元数据最多可描述：

- 契约版本和生成时间；
- 每个候选的秘密安全指纹或可关联的匿名标识；
- 采集时间、过期时间和服务端弱参考分数；
- 服务端检查的有限状态和协议能力。

不得包含完整代理 URL、认证材料、UUID、私钥、用户 IP、设备标识、浏览记录或测试载荷。只有在确有必要时才认证元数据端点；认证机制不得成为普通订阅的前提。

## 兼容性和变更

任何字段新增必须保持旧客户端可忽略。删除或改变已发布字段前，先提供向后兼容读取和迁移测试。契约变更应同时更新本文件、服务端实现和客户端测试夹具。
