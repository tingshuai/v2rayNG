# 来源审查记录

本文件记录来源接入决定及其可复核依据；不记录订阅 URL、节点配置、凭据、UUID 或私钥。实际来源地址仅保存在部署环境的来源注册表中。

下表是 2026-11-09 的历史准入快照，并非当前启用状态或 FN-2.0 的候选筛选结果。FN-2.0 的来源获取、跨来源合并与轮转规则以 [实施方案](implementation-plan.md) 和 [运行手册](collector-runbook.md) 为准。

## 当前准入语义

按项目维护者于 2026-11-09 的明确指示，当前阶段只以技术可用性决定是否接入公开、无需认证的来源；不因授权、再分发许可、署名或同许可条件阻断接入，也不为这些事项实施额外流程。这个决定不放宽安全边界：来源仍必须经 HTTPS 拉取、受体积和频率限制、可解析，并通过公网地址、DNS 重绑定防护及完整连通性筛选后才会进入发布订阅。
