# FN-2.0 Android 状态与选择

**FN-2.0 实施状态：部分实现，尚未完成验收。** 客户端使用 MMKV、受生命周期约束的后台任务、真实连接测试和 Xray 策略组能力。免费节点功能由用户主动开启；未开启时原有 VPN、仅代理、root 和订阅行为不变。

当前标准订阅更新仍替换专用订阅；替换前，客户端以连接字段的设备本地 HMAC 指纹查询 MMKV 历史，将最近 7 天内测通且未隔离的最多 16 条缺席旧配置并回新订阅。Xray 专用策略组只纳入至少一次本机测通且未隔离的 profile；未测新候选与隔离候选通过现有有限 `RealPingWorkerService` 后台抽样探索。该合并使用现有批量 profile 保存操作。版本化 manifest、安全撤销与过期删除尚未接入；本地失败历史仅在关闭功能时清除。

后台仅测有限候选：近期健康、未测新节点、隔离到期的少量探索样本。当前实现每批最多测 8 条（4 条健康、2 条新候选、2 条隔离恢复），要求有网络且电量不低。连续 3 次失败后隔离 30 分钟；最近 7 天内测通且缺席的配置最多保留 16 条。当前节点保持由现有 Xray 策略组/balancer 管理；本机评分在挑战者连续两轮领先 800 分后更新本地优选记录。未实现额外自动改写用户选中服务器。服务端质量分数和 manifest 仍未接入。

匿名质量反馈端点和客户端设置尚未实现，因此当前不发送探测报告。启用前继续展示免费节点不适合凭据、支付等敏感流量的警示。

测试必须覆盖清单更新时旧好节点保留、失败节点退出、冷却后恢复、安全撤销、当前节点稳定、后台取消/约束、反馈开关和网络健康前置条件，以及 VPN、仅代理和 root 受影响路径。
